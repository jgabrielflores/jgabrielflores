### 🚀 Projeto em destaque

#### [Ramos Planejados](https://github.com/jgabrielflores/ramos-planejados) — Plataforma fullstack de gestão de pedidos

Sistema fullstack que substitui o controle informal (WhatsApp/planilhas) de uma marcenaria de móveis
planejados por uma plataforma estruturada. Monorepo com backend FastAPI e frontend Next.js.

- 🔐 **API REST** em FastAPI com autenticação JWT, SQLAlchemy 2.0 e PostgreSQL.
- 🧪 **133 testes** (unitários, integração e segurança) com **~91% de cobertura** e CI no GitHub Actions.
- 🛡️ Práticas **OWASP ASVS**: proteção contra SQL Injection, IDOR, força bruta (rate limiting) e CORS restrito.
- 🏗️ Arquitetura em camadas, máquina de estados de pedidos e dashboard com agregações SQL (KPIs financeiros).
- 🎨 Frontend em **Next.js + TypeScript** com Tailwind CSS e shadcn/ui.

`FastAPI` `PostgreSQL` `SQLAlchemy` `Alembic` `Pydantic` `pytest` `Docker` `GitHub Actions` `Next.js` `TypeScript`
